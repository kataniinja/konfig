# Virtual File System Shell Emulator

Это проект, представляющий собой эмулятор командной оболочки, работающий с виртуальной файловой системой, загружаемой из архива TAR. Эмулятор поддерживает базовые команды командной строки, такие как `ls`, `cd`, `whoami`, `date`, и `clear`, а также позволяет взаимодействовать с файловой системой, состоящей из директорий и файлов.

## Описание
Этот проект представляет собой оболочку, которая эмулирует работу с файловой системой, используя архивацию данных в формате TAR. Эмулятор поддерживает выполнение различных команд, таких как просмотр содержимого директорий (`ls`), изменение текущей директории (`cd`), вывод текущей даты (`date`), а также другие стандартные команды оболочки.

```csv
username,archive_path,startup_script
user1,virtual_fs.tar,startup_script.txt
```
Запустите эмулятор, передав путь к конфигурационному файлу:
```bash
python shell.py config.csv
```
Теперь вы можете использовать эмулятор, вводя команды, такие как:
```bash
ls
cd virtual_fs
whoami
date
clear
```
### Тестирование
Для выполнения тестов убедитесь, что у вас установлен модуль unittest.
Для запуска тестов используйте команду:
```bash
python test_shell.py
```
